# 加密匯出（伺服器版與想要加密的個人使用者）

- **狀態**：待處理（這一輪沒做）
- **擁有者原話**：「給別人下載的時候就直接用一個 ZIP 去加密然後可能就讓他知道自己的密碼這樣就好……如果是雲端使用者那為了怕有風險那當然我們就可以做好加密……這邊也可以跟我討論一下」（語音轉字，ZIP 原本辨識成 VIP）

## 問題一句話
現在個人版可以下載沒加密的 CSV（下載前會提醒），伺服器版一律不能匯出；要加密的版本還沒定做法。

## 脈絡
- 「打亂按鈕的小遊戲」擋得住旁邊偷看，擋不住架 SYNOX 的管理員（按鈕是伺服器產生、按了也傳回伺服器）。
- Python 內建做不出加密 zip；Windows 檔案總管只打得開舊式（很弱的）加密 zip，強的 AES 要 7-Zip。
- 要讓管理員不知道密碼：在你的瀏覽器裡輸密碼、在瀏覽器裡加密。

## 選項
| 選項 | 一句話 | |
|---|---|---|
| A | 在瀏覽器裡用你設的密碼加密，產生 7-Zip 打得開的 AES zip | **建議** |
| B | 伺服器端加密 zip（要多一個套件；管理員理論上碰得到密碼） | |
| C | 維持現在（個人版明文、伺服器版不能匯出） | |

## 驗收
- 寫 ADR（擴充 0024 的 `web.app.exports`），伺服器版改成只允許加密匯出，測試涵蓋「密碼不經過伺服器」。

## 不要做的事
- 不要在沒有設計前就把伺服器版的匯出打開。
