# 主機台解鎖後，同一個登入開的工具網頁也算解鎖？

- **狀態**：待處理（照建議先做了，等擁有者確認）
- **擁有者原話**：「某一些權限要開到剛剛好，不要讓他去做一些很奇怪的事情。」

## 問題一句話
開了「保護危險動作」後，工具網頁上沒有輸驗證碼的地方；目前做法是：你在主機台解鎖（15 分鐘），從同一個主機台登入開的工具網頁也跟著解鎖。

## 脈絡
- 不這樣做的話，開了保護之後，工具網頁上的危險動作（例如刪一整個類別以外的 DANGER 動作）就完全做不了。
- 手機入口不受影響：手機上一律不能做危險動作。

## 選項
| 選項 | 一句話 | |
|---|---|---|
| A | 維持現在：主機台解鎖帶到它開的工具網頁 | **建議（已做）** |
| B | 工具網頁自己加一個輸驗證碼的小框，各自解鎖 | |
| C | 工具網頁一律不能做危險動作，要做回 Telegram 或主機台 | |

## 驗收
- 選 B／C 時：改 `src/synox/apps/` 與 appkit，補測試，更新 ADR 0025。

## 不要做的事
- 不要讓 AI、排程或手機入口拿到這個解鎖。
