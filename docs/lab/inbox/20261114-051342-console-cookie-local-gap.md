# 主機台的登入 cookie：同一台電腦的其他程式拿得到

- **狀態**：待處理（這一輪之前就有的問題）
- **擁有者原話**：「我覺得最讓人擔心的就是說，到底要怎麼樣透過一些漏洞去繞開我的網路，然後攻擊我的電腦，或者是去偷走我的一些資料。」

## 問題一句話
瀏覽器不會照埠分開 cookie：這台電腦上別的帳號或程式只要在 `127.0.0.1` 的某個埠聽著、騙你點一下，就能收到主機台的登入。

## 脈絡
- 工具網頁這次已經避開（換位址、不用 cookie）；主機台本身沒改。
- 有手機驗證器時，拿到登入也做不了敏感的事；但看得到資料本身就是問題。
- 個人版的「本機自動登入」也讓同一台電腦的另一個 Windows 帳號直接進得來。
- 證據：`docs/security/web-threats.md` 第 6b、26 列；`docs/lab/issues-to-open.md` 第 5 項。

## 選項
| 選項 | 一句話 | |
|---|---|---|
| A | 主機台也改成不靠 cookie（每個分頁一個標頭 token，跟工具網頁同一套） | **建議** |
| B | 主機台改綁專用位址＋cookie 加上更嚴的檢查 | |
| C | 先只在說明裡提醒共用電腦的人關掉自動登入 | |

## 驗收
- 寫 ADR；改完後「另一個本機埠收到主機台 cookie」的測試要失敗（收不到）。

## 不要做的事
- 不要在這台電腦開真的埠去「驗證」這個洞。
