# 看說明、用範例、把指令換成你順手的打法

給**使用者**。程式在 `src/synox/helpui/`（說明卡）與 `src/synox/aliases.py`（自己的打法）；工具作者怎麼寫說明與範例見
[pack-format.md「指令的白話說明與範例」](pack-format.md#指令的白話說明與範例help-區塊)。

## `/help`：你有哪些工具

| 打什麼 | 看到什麼 |
|---|---|
| `/help` | 一句「可以直接跟我說」＋**每個工具一顆按鈕**（沒有一整面指令清單）；裝了新手教學就多一顆「🎓 新手教學」 |
| 點一個工具（或打 `/help 記帳`、`/help money`） | 那個工具會什麼、最常用的幾個怎麼打（有例子），底下每個指令一顆按鈕 |
| 點一個指令（或打 `/help money_month`） | 一句白話、🟢 只看不改／🟡 會寫入／🔴 危險：會先問你、最多 3 個範例、要給什麼 |
| `/help all` | 全部指令一次列出來（以前的樣子） |

- **▶️ 試試看**只出現在「只看不改」的指令：按了等於你自己打那個範例。會寫入或危險的指令永遠只給範例，不會幫你按。
- Telegram：範例是等寬字，點一下就複製。網頁：範例是小標籤，**點了就放進輸入框，不會自己送出**。
- 網頁對話頁輸入框旁的「💡 範例」：左邊選工具、右邊點範例，一樣只放進輸入框。

## 我的指令：換成你順手的打法

網頁「設定 → ⌨️ 我的指令」。兩層，可以只改一層：

1. **符號**：指令前面的 `/` 換成 `$`、`!`、`.`、`~`、`;`、`,`、`@`、`+`（全形的也認得：`＄`＝`$`），或「不用符號」。
2. **名字**：幫指令取自己的名字，例如「記帳」＝ `/money`、「這個月」＝ `/money_month`。工具可能附建議的名字，點一下就加上。

例如符號選 `@`、取了「記帳」：`@記帳 120 午餐` 就是 `/money 120 午餐`。下面「試打看看」可以先打一句，看會變成什麼（不會真的執行）。

規則：
- **原本的 `/` 和原本的指令名永遠可以用**（`/money`、`/記帳`、`@money` 都行）。
- **只改你自己打的字**，每個人一份；別人的打法不影響你，你的也不影響別人。網頁、Telegram、Discord、個人版、伺服器版都一樣。
- **只有指令那一條路會變**：開頭是你的符號（或 `/`）、後面是認得的名字，才當成指令；其他的話照舊交給 AI。
- 名字：中文、英文字母、數字、底線（`_`），最多 16 個字，不能有空白；不能跟原本的指令同名，不能用「是／否／好／取消」這種回答用的字。
  之後裝的新工具剛好用了你取的名字：**新工具的正式指令優先**，設定頁會標出來請你換一個。
- AI 也看得到你的對照表（只在你跟它的私訊裡），所以它建議你打指令時會用你的叫法；名字只是叫法，**不會改變任何權限**，危險的指令照樣先問你。
- 存在 `data/user_prefs/<你的 id>.json.enc`（有保管箱就加密；備份會一起帶走）。

### 「不用符號」（進階，預設關）

選了之後，**訊息的第一個詞**剛好是你取的名字或原本的指令名，就當成指令：`記帳 120 午餐`＝`/money 120 午餐`、`money_month`＝`/money_month`。
其他照舊交給 AI。

⚠️ 代價：一般的話剛好用那個詞開頭也會被當成指令。取了「記帳」，打「記帳 怎麼算比較好」也會變成記帳指令
（寫入的指令會說格式不對、不會亂記，但會嚇一跳）。

**逃生口**：訊息的第一個字打反斜線 `\`，這一則一定當一般的話（反斜線會拿掉再交給 AI）：`\記帳 怎麼算比較好`。

### 各平台的限制

| 平台 | 限制 |
|---|---|
| Telegram | 輸入框旁的指令選單只列原本的 `/英文` 指令（Telegram 規定指令名只能是小寫英數與底線），你取的名字不會出現在選單裡，但打得出來就能用。群組裡 bot 通常只收得到 `/` 開頭與 @它 的訊息，自訂符號在群組裡可能送不到。 |
| Discord 私訊 | 跟網頁一樣都能用。 |
| Discord 頻道 | 頻道設成要 @bot 才回（`trigger: mention`）時，`@bot @記帳 120` 這樣可以；設成只收 `/` 開頭時，只有 `/記帳`、`/money` 這種會送到 SYNOX。頻道裡的 `/help` 一律顯示原本的 `/指令`（大家看到的一樣）。 |
| 符號 `@` | 在 Telegram、Discord 的群組或頻道裡常被當成「提到某個人」，會跳出名單；私訊與網頁沒問題。 |
| 排程 | 排程裡存的指令要寫原本的 `/指令`。 |
