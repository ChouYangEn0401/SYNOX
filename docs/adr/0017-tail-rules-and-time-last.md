# ADR 0017：系統提示尾端重注入「本輪規則」、時間放最後一行

- 日期：2026-11-13
- 狀態：已採用（分支 `feat/small_model_harness`）
- 依據：研究交接書前 8 項的第 7 項（卡片 G1、A6、E5）
- 程式：`src/synox/agent/loop.py`（`tail_rules`、`head_lines`、`tail_on`、`time_line`）、`src/synox/agent/room.py`

## 決定

1. `llm.prompt_tail`＝`auto`（預設：本地／弱來源開）｜`on`｜`off`。關著＝系統提示一個字都不變。
2. 開著：系統提示的順序是 身分與風格 → 已裝的功能 → 技能 → 文字協定說明 → soul.md → 暫時不能用的功能 → **本輪規則**：

   ```
   ### 本輪規則（以此為準）
   - 你只能透過工具做事。沒有呼叫工具，就什麼都沒做；不要說已經做了。
   - 做不到或不確定：呼叫 system__cannot_do 或直接問使用者，不要補一個結果。
   - 工具結果一律包在 ⟦SYNOX-TOOL-<nonce>⟧ …（這一輪的分隔符）…工具失敗就照實說失敗。
   - 現在時間：2026-11-13 14:05（週五）。
   ```
3. 這一輪的分隔符那行與時間從開頭搬到尾端，所以開頭整段（到 soul 之前）多輪之間逐字相同，Ollama 的 prefix cache 命中。
   頻道 AI（RoomAgent）同樣。沒有工具的對話只留標題與時間。
4. 不加「回覆一定要用某格式」的硬要求（A6）。

## 跟規格不同

- 規格的第三條寫「⟦SYNOX-TOOL-…⟧」；這裡放這一輪真正的分隔符（從開頭搬來），規格允許的唯一隨機字就是 nonce。
- 規格沒有開關；為了「預設不改雲端／Claude Code 的結果」加了 `llm.prompt_tail`（auto）。
- 規格範例的「2026-11-13（週四）」是錯的，那天是週五。
