把 SYNOX 接上 Telegram

從跟 @BotFather 要一支 bot、拿到 token，到貼進 SYNOX、配對你的帳號、收到第一句話。全程大約五分鐘，不用打任何指令到電腦的黑視窗裡。

  1. 跟 @BotFather 拿 token
  2. 貼進 SYNOX，檢查 token
  3. 配對：傳六個數字
  4. 第一則訊息
  5. 常見問題

這一頁的圖都是示意圖，不是真的截圖：畫的是畫面上會出現的東西和位置，Telegram 的實際字句、顏色會跟你的手機版本略有不同。

開始前，準備好這三樣

  • 一個 Telegram 帳號，手機（或電腦）上已經裝好 Telegram 並登入。
  • 電腦上已經雙擊過 Setup.bat，安裝精靈停在「Bot 的 token」那一頁；或者 SYNOX 已經在跑，你打開了網頁的「設定 → 聊天通道」。
  • 手機和電腦都能上網（精靈會替你去問 Telegram）。

bot 是什麼？你可以把它想成「一個只跟你講話的 Telegram 聯絡人」。它的本體是你電腦上的 SYNOX；token 就是這個聯絡人的鑰匙，SYNOX 拿著鑰匙才能替它收訊息、回訊息。

1

跟 @BotFather 拿 token

BotFather 是 Telegram 官方用來「製造 bot」的 bot。所有 Telegram bot 都是在這裡誕生的。

1-1 找到正牌的 BotFather

  1. 打開 Telegram，點上面的搜尋，輸入 BotFather。
  2. 點進帳號是 @BotFather、名字旁邊有藍色勾勾（官方認證）的那一個。
  3. 第一次打開會看到一顆藍色的 START（開始）按鈕，點它。

搜尋結果裡常有名字很像、沒有藍勾勾的假帳號（例如 Bot_Father、BotFather_official）。只認 @BotFather 加藍勾勾；把 token 交給假帳號等於把鑰匙給陌生人。

1-2 傳 /newbot，回答兩個問題

  1. 在對話框輸入 /newbot 送出（也可以按左下角的「選單」從清單裡點）。
  2. 它會問名字（name）：這是顯示用的，中文、空格都可以，之後能改。例如「我的小助手」。
  3. 再問帳號（username）：只能用英文字母、數字、底線，5 到 32 個字，結尾一定要是 bot（例如 amy_helper_bot）。帳號在整個 Telegram 裡不能重複，被用掉了它會說「already taken」，換一個再傳就好。帳號之後不能改，名字可以。
  4. 它回「Done! Congratulations on your new bot.」那一則裡，「Use this token to access the HTTP API:」下面那一整串就是 token。

1-3 把 token 整串複製起來

  • 手機：長按那一串 token，Telegram 會把它整段選起來，點「複製」。
  • 電腦版 Telegram：點一下 token 通常就會複製（右下角跳出「已複製」）；或用滑鼠選取整串再 Ctrl+C。
  • 要複製完整的一串：從冒號前面的數字一路到最後一個字，前後不要多空格、也不要少字。精靈會幫你檢查格式。

token 等於這支 bot 的密碼。不要貼到群組、截圖分享、或交給任何網站。真的不小心外流了，看下面的常見問題「換一組 token」，一分鐘就能作廢重發。

之後要再看 token：對 BotFather 傳 /mybots → 點你的 bot → API Token。

2

貼進 SYNOX，按「檢查 token」

兩個地方都可以貼：第一次安裝用安裝精靈；SYNOX 已經在跑、想補接或換 token，用網頁的設定頁。

2-A 安裝精靈（第一次安裝）

  1. 精靈第 2 頁「Bot 的 token」，上面「用哪一個」選 Telegram（預設就是）。
  2. 點進輸入框，貼上剛剛複製的 token（Ctrl+V，或右鍵 → 貼上）。
  3. 按「檢查 token」。精靈會去問 Telegram 這把鑰匙開得了哪支 bot，幾秒內顯示「✅ 這支 bot 叫 @你的帳號」。
  4. 「下一步」亮起來了，按它進到配對。

看到紅字？對照常見問題「token 檢查沒過」。還沒有 bot 也可以先按「先跳過，晚點再補」，之後再雙擊 Setup.bat 回來填。

2-B 網頁設定頁（SYNOX 已經在跑）

  1. 打開 SYNOX 網頁（雙擊桌面的「SYNOX」捷徑，或 SYNOX 資料夾裡的 Open-SYNOX.bat）。
  2. 左邊選「設定」，找到「聊天通道」這張卡，Telegram 那一格。
  3. 貼上 token，按「檢查並存起來」。通過會顯示「✅ token 已存：bot @你的帳號」。
  4. 卡片上會出現黃色的「要重新啟動 SYNOX」提醒：先雙擊 Stop.bat，再雙擊桌面的 SYNOX 捷徑。重開之前 bot 不會上線。

存好之後網頁不會再顯示 token 本身（只看得到是哪支 bot），這是刻意的。

3

配對：把六個數字傳給你的 bot

SYNOX 要知道「哪個 Telegram 帳號是主人」。方法很簡單：電腦畫面給你六個數字，你用手機傳給 bot，SYNOX 看到就認得你了。別人就算找到你的 bot，沒有這六個數字也進不來。

3-1 電腦這邊：拿到六個數字

  1. 精靈第 3 頁「你是誰」會顯示一組六位數字，下面寫著「⏳ 等你傳過來…」。
  2. 按「打開 t.me/你的bot」按鈕，瀏覽器會幫你跳到 Telegram 並打開這支 bot 的對話（手機上也可以直接在 Telegram 搜尋你剛取的帳號）。

用網頁設定頁的話：Telegram 那一格按「產生配對碼」，一樣會出現六個數字；接下來的動作相同。

數字有效 15 分鐘。超過會顯示「⌛ 等太久了」，把精靈關掉、再雙擊 Setup.bat 重來一次就好，不會壞掉什麼。

3-2 手機這邊：傳數字

  1. 打開你的 bot 之後，先按最下面的 START（開始）。第一次跟任何 bot 講話都要按這一下。
  2. 把那六個數字直接打出來送出（例如 429170；中間有沒有空格都可以）。
  3. 幾秒內 bot 會回「✅ 配對成功！回到電腦上的安裝畫面，按『下一步』。」
  4. 回到電腦：畫面變成「✅ 認得你了：@你的帳號（id 一串數字）」，按「下一步」去設定 AI。

bot 沒回？看常見問題「傳了數字沒反應」。

4

第一則訊息

精靈的最後一頁按「完成並開始」，SYNOX 就會開起來（一個縮小的小視窗，那就是 bot 本人）。

手機會收到「我在了」

  1. 幾秒內，你的 bot 會傳來「👋 我在了，按 /help 看我會什麼。」看到這句，就全部接通了。
  2. 回它 /help，它會列出現在會的指令。剛裝好的 SYNOX 只有系統指令（提醒 /remind_add、網頁 /web…），記帳、筆記這些要另外裝工具。
  3. 有設定 AI 的話，直接用人話講也行，例如「明天早上八點提醒我吃藥」。

以後要開 bot：雙擊桌面的「SYNOX」捷徑（或 Start.bat）。關掉那個小視窗（或雙擊 Stop.bat）bot 就下線；下線時手機傳訊息它不會回，開回來也不會補回。

常見問題

照出現的錯字找。每一題都是先講「為什麼」，再講「怎麼做」。

「❌ 這看起來不是 token」或「token 不對（Telegram 說 401）」

「這看起來不是 token」：貼進來的字格式不對。token 一定是「一串數字 : 一串字母數字」，中間有一個冒號。常見原因：只複製到一半、多貼了前後的字（例如把「Use this token…」那句也貼進來）、或貼成 bot 的帳號（@xxx_bot）。回 BotFather 那則訊息，重新長按、整串複製。

「token 不對（Telegram 說 401）」：格式對，但 Telegram 說這把鑰匙不存在或已作廢。常見原因：

  • 你後來在 BotFather 按過「Revoke」或傳過 /token，舊的那串已經失效，要用新的。
  • 複製時少了一個字，或多了一個字（看起來很像但其實不同）。
  • 貼到的是別支 bot 的舊 token。

最快的做法：對 BotFather 傳 /mybots → 點你的 bot → API Token，它會把現在有效的 token 再給你一次，整串複製回來貼。

「連不到 Telegram：檢查網路」：電腦這一刻上不了 Telegram 的伺服器。換個網路、關掉 VPN 或防火牆再按一次「檢查 token」。

傳了六個數字，bot 沒反應
  • 有沒有先按 START？還沒按之前，你打的字送不出去。
  • 傳對 bot 了嗎？要傳給你剛建的那支 bot（精靈畫面上寫的那個帳號），不是傳給 BotFather。
  • 數字還在有效期內嗎？精靈上的數字 15 分鐘有效；畫面已經顯示「⌛ 等太久了」就重來：關掉精靈、再雙擊 Setup.bat。
  • 要用私訊傳，不要在群組裡傳。而且要用你自己的帳號傳（別的 bot 傳的不算）。
  • 精靈畫面還是「⏳ 等你傳過來…」而且過了一分鐘：電腦的網路可能斷了，精靈每幾秒會再試一次，連回來就會收到。
配對好了，之後 bot 都不回我

依序檢查這幾件事，九成的情況在前三項：

  1. SYNOX 有開著嗎？電腦上要有那個縮小的 SYNOX 小視窗（工作列上看得到）。沒有就雙擊桌面的「SYNOX」捷徑。電腦關機、睡眠時 bot 也會下線。
  2. 小視窗裡有沒有紅字？點開看最後幾行。常見是 token 失效（401）、或網路不通。
  3. 你是用配對的那個帳號嗎？個人版只回配對過的主人，別的帳號傳訊息它會當作沒看到。換了手機號碼、換了 Telegram 帳號就要重新配對（網頁設定 → 聊天通道 → Telegram → 重新配對）。
  4. 是在群組裡嗎？SYNOX 現在只回私訊（一對一）。把 bot 拉進群組、在群組裡 @ 它，它不會回，見下面「群組」那題。
  5. 剛在網頁改過 token？要重新啟動 SYNOX（Stop.bat → 桌面捷徑）才生效。
  6. 還是不行：在 SYNOX 資料夾雙擊 Console.bat，可以不連 Telegram 直接在電腦上試指令；或開命令列跑 .venv\Scripts\python.exe -m synox doctor，它會逐項檢查並用人話說哪裡有問題。
token 外流了、想換一組 token

token 誰拿到都能操控你的 bot，所以一旦貼錯地方、截圖傳出去，就直接作廢重發。bot 本身、它的名字和帳號都不會變，只是換一把鑰匙。

  1. 對 BotFather 傳 /mybots → 點你的 bot → API Token → Revoke current token。它會立刻給你一串新的（舊的那串從這一刻起就失效）。
    也可以直接傳 /revoke（作廢並重發）或 /token（重發），BotFather 會先問你要處理哪一支 bot。
  2. 把新的 token 貼回 SYNOX：網頁設定 → 聊天通道 → Telegram → 貼上 → 「檢查並存起來」；或再雙擊 Setup.bat 走一次精靈。
  3. 重新啟動 SYNOX（Stop.bat → 桌面捷徑）。舊 token 失效的那一刻起、到你重開之前，bot 是下線的。

配對不用重做：換鑰匙不影響「誰是主人」。

隱私模式（Privacy mode）要不要開？

隱私模式是 Telegram 對 bot 的一個設定，只影響 bot 在群組裡看得到哪些訊息：開著（預設）時，bot 在群組只收得到指令（/xxx）、回覆它的訊息、@ 它的訊息；關掉時群組裡每一句它都收得到。私訊永遠不受影響，bot 在一對一對話裡本來就收得到全部。

SYNOX 現在只在私訊裡工作，所以這個設定你不用動，維持預設（開著）就好。這也是對群組裡其他人比較禮貌的設定。

如果你還是想改：對 BotFather 傳 /setprivacy → 選 bot → Enable／Disable。注意 Telegram 的規則：改了隱私模式之後，bot 要從群組移除、再加回去，新設定才會對那個群組生效。

可以把 bot 拉進群組一起用嗎？

目前不行。SYNOX 的指令和 AI 在 Telegram 群組裡都會被擋掉，這是刻意的：群組裡的人不該碰得到你電腦上的筆記、記帳和提醒。把 bot 加進群組之後，它在群組裡不會回任何話（私訊照常）。

想讓家人、同事也用：裝的時候選「一群人（伺服器版）」，每個人各自私訊你的 bot，你用 /user_list、/user_role 決定誰能用什麼；每個人的資料各自加密、互相看不到。詳情見 SYNOX 的 README「個人版和伺服器版」。

想改 bot 的名字、頭像、說明

這些都在 BotFather 改，跟 SYNOX 無關、不用重新貼 token。傳指令之後它會先問你要改哪一支 bot：

/setname
改顯示名字（帳號 @xxx_bot 不能改）。
/setuserpic
換頭像：傳指令後，把一張圖片傳給它。
/setdescription
對話開頭「這個 bot 能做什麼」那段說明，最多 512 字。
/setabouttext
個人頁上的簡介，最多 120 字。
/setcommands
打「/」時跳出的指令提示清單（SYNOX 啟動時會自己設一份，通常不用手動改）。
/mybots
用按鈕的方式看全部設定、拿 token、作廢 token；上面這些指令在裡面都找得到。
取帳號時它說「Sorry, this username is already taken」

帳號在整個 Telegram 裡不能重複，被別人用掉了。換一個再傳給它就好（不用重來 /newbot）：加上你的名字、數字或底線，例如 amy_home_helper_bot。規則：5 到 32 個字、只能英文字母／數字／底線、結尾一定是 bot（大小寫不分）。

它說「Sorry, this username is invalid」通常是結尾不是 bot，或用了中文、空格、連字號。

換了一台電腦，token 要重拿嗎？

不用。token 跟 bot 綁在一起，不綁電腦。新電腦上雙擊 Setup.bat，到第 2 頁時到 BotFather 傳 /mybots → 你的 bot → API Token 拿同一串貼上即可；配對也要再做一次（六個數字）。

但要注意：同一個 token 同一時間只能有一台電腦在跑。舊電腦的 SYNOX 要先關掉（雙擊 Stop.bat），不然兩邊會搶訊息，兩邊都時好時壞。另外，筆記、記帳這些資料是綁舊電腦加密的，不會自動搬過去，見 README「換電腦？」。

這一頁放在 SYNOX 資料夾的 docs/tutorials/telegram/index.html，離線也打得開；純文字版在旁邊的 README.md。安裝精靈 token 那一頁的「看圖文教學」、網頁設定「聊天通道」的連結，開的都是這一頁。

BotFather 的指令與規則依 Telegram 官方文件（core.telegram.org/bots）整理，2026 年 11 月確認；Telegram 改版時以它實際的畫面為準。畫面示意圖是手繪的，不是截圖。
