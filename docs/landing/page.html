放心用

你的資料，留在你的電腦

存在你的硬碟沒有雲端帳號。筆記、記帳、提醒都加密存，只有這台電腦解得開。
只有兩條路出門訊息會經過 Telegram／Discord；接了 AI 時，送出你那句話和最近幾輪對話。
危險的事先問你刪除、花錢、動到外面服務：AI 只能送確認卡，你按了才做。
裝工具前先檢查每個工具先掃描、給你看報告；裝好後被改過就不載入。

網頁只給這台電腦自己用（127.0.0.1）。完整說明在 repo 的 docs/security.md。

給開發者

寫一個函式，就是一個工具

一個工具一個資料夾，壓成 .synoxpack 就能給別人裝。裝好後，它同時是聊天指令、AI 能用的工具、網頁上的一張卡。

任何語言 命令列程式，JSON 進、JSON 出
MCP 伺服器 已經有的 MCP 直接接
遠端 MCP 別人架好的服務，只寫一份宣告
寫工具從這裡開始 Python SDK 範例 工具庫：現有的工具 
from synox_sdk import tool, serve

@tool("READ")
def greet(name: str):
    """跟某人打招呼。"""
    return f"嗨 {name}！"

if __name__ == "__main__":
    serve()

# 打包成一個檔，給別人點兩下就裝
synox-sdk init --from tool.py --name hello
synox-sdk zip .   → dist/hello-0.1.0.synoxpack
