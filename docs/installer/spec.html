一句話目標

下載一個檔案，一路按「下一步」，SYNOX 就能用。

不懂電腦的人用建議值就全部裝好；懂的人可以自己調。這台電腦原本的 Python、Conda 和其他程式，一樣都不動。

4次點擊走完建議安裝：語言「確定」、「下一步」、「安裝」、「完成」
0個指令，不用打字。⏳ 但按「完成」後還會開一個黑色文字視窗裝套件，還沒藏起來
0次系統管理員密碼。裝在你自己的使用者資料夾
1個資料夾。程式、SYNOX 自己的 Python、你的資料都在裡面
現在的狀態（2026-11-13）：畫面和流程寫好了，還沒在 Windows 上試過。今天做好三件事：安裝程式的新畫面、不用 uv 的自帶 Python、新手教學。🧪 .exe 從來沒有編譯過，第一次跑 CI 才是真的測試。細節見第 7 節和第 8 節。

這份規格跟其他文件的關係

擁有者問：文字視窗要不要丟？安裝程式要不要留？跟「一步一步教學」有沒有連在一起？答案：都留著，各管各的事，而且一起更新。

  • 一步一步教學：給使用者

    一步一步教學是使用手冊，只寫今天就能裝的方法：下載 ZIP、雙擊 Setup.bat。

  • 這份規格：給開發者

    這一頁是新安裝程式的藍圖，正在照著做。給開發者和 agent 看，不是給使用者照著裝的。

  • .exe 出來時，一起改

    新的 .exe 出貨時，教學的主要方法換成 .exe，ZIP 留作「另一種方法」。教學和安裝程式在同一次修改裡更新。

  • 文字視窗不丟

    Setup.bat 的文字視窗留著：ZIP 這條路要用它，開不了 .exe 的人也靠它。大多數人走 .exe，看不到文字視窗。

  • 工程師的作法：另外寫

    原始碼＋venv、Docker、無畫面執行這類進階作法，寫在 docs/advanced-install.md，不放進教學，也不放在這裡。已有

五條原則

每一頁畫面、每一句話都拿這五條檢查。有一條不過，就還不能出貨。

  • 不用開終端機

    從下載到手機收到「我在了」，使用者只按按鈕、貼一次 token。看不到黑色視窗，也不用知道 Python 是什麼。⏳ 還沒做到 今天 .exe 按「完成」後，還會開 Setup.bat 的黑色視窗裝套件。

    檢查方法：找一位不寫程式的人，不給任何提示，看他能不能自己裝完。

  • 講白話

    畫面上不出現 venv、pip、PATH、HKCU 這些字。要講就講它做什麼：「SYNOX 自己的 Python」「點兩下就能安裝」。

    工程用語只放在「顯示詳細過程」和紀錄檔裡。

  • 失敗時說下一步

    每個錯誤畫面都回答三件事：發生什麼事、你的東西有沒有受影響、現在該按哪一顆。不丟錯誤代碼給使用者。

    見第 6 節。前四個失敗畫面還沒做。

  • 建議值先選好

    每個問題都有一個已經選好的答案，直接按「下一步」就是完整可用的 SYNOX。想改的人選「自訂」，像 Git for Windows 那樣一項一項調。

  • SYNOX 資料夾以外的東西，你選了才動

    程式、SYNOX 自己的 Python、資料都放在同一個資料夾。資料夾外面只會做你在畫面上看得到、而且勾了的事（捷徑、開機啟動、檔案類型、Claude Code），每一項都能取消，解除安裝時會收乾淨。

選語言

新的待實測

這頁現在是這樣

  • 安裝程式一打開，第一件事就是選語言，在歡迎頁之前。之後安裝程式的每一頁、設定精靈、SYNOX 都用這個語言，不會再問一次。
  • 用的是 Inno Setup 自己的語言小視窗：標題「語言 · Language」、一個下拉選單、「確定」和「取消」。清單照名字排，順序由 Inno 決定。待實測
  • 預選 Windows 的顯示語言；對不上 12 種就預選 English。大多數人直接按「確定」。
  • 12 種的代號跟 i18n.LANGS 一樣：zh-TW、zh-CN、en、es、fr、de、pt-BR、ru、ar、hi、ja、ko。每一種寫「原文名 (英文名)」，例如「繁體中文 (Traditional Chinese)」。
  • 更新時照樣顯示這頁，預選上次選的語言。
  • 繁體中文、简体中文、हिन्दी：Inno 內建的按鈕和內建頁面先用英文。Inno Setup 沒有這三種的官方語言檔；非官方的檔要不要用，等擁有者決定授權（Q10）。SYNOX 自己的字 12 種都翻了。
  • 12 種的字是模型翻的，要請母語的人校對。🧪 待校對
  • 像上一版圖那樣自己畫的清單頁（一格一種語言＋「下一步」）還沒做。⏳ 尚未完成
  • 選 العربية 時畫面由右到左排（Inno 官方的 Arabic 語言檔）。待實測
  • SYNOX 本身也要照這個語言開。設定精靈會把語言寫進 config.json 的 "language"，但 SYNOX 的網頁介面和 bot 的話還不讀它。要改

怎麼做的

Inno Setup
ShowLanguageDialog=yes、LanguageDetectionMethod=uilanguage、UsePreviousLanguage=yes。每個語言的名字寫在它的 .isl 的 [LangOptions] LanguageName。
語言檔
[Languages] 列 12 種，每種疊三層：Inno 的語言檔（按鈕這類內建的字）→ lang\en.isl → lang\<代號>.isl（我們自己的字；缺哪句就退回英文）。8 種用 Inno 官方檔；另外 3 種看 lang\inno\ 有沒有放檔，沒有就用英文的 Default.isl。
交下去
檔案複製完，安裝程式把代號寫進 SYNOX 資料夾的 lang.txt 和 installer-choices.json；完成頁用 Setup.bat -Lang <代號>，再用 --lang 開設定精靈，精靈就跳過自己的語言頁。Uninstall.bat 也讀同一個 lang.txt。
ZIP 路徑
Setup.bat 的文字視窗第一題就是語言（lang.ps1）：12 種排兩欄，打數字或代號；直接按 Enter＝Windows 的顯示語言。存進 lang.txt。給了 -Lang／SYNOX_LANG，或已經有 lang.txt，就不問。已有

安裝之後

接著的設定精靈

安裝程式負責「把程式裝好」，設定精靈負責「接上你的帳號」。精靈支援 12 種語言；下面是它的五頁，字是現在程式裡的字。視窗標題今天還叫「SYNOX 安裝精靈」。

已有語言那一頁會自動跳過

語言在安裝程式第 1 頁（ZIP：Setup.bat 第一題）就選好了，用 --lang 交給精靈。只有直接打開精靈、又沒選過語言的人才會看到「Language / 語言」。

新的最後一頁不再重問一次

從安裝程式來的人（SYNOX 資料夾有 installer-choices.json），這頁只有「完成後立刻開啟 SYNOX」。從 ZIP 來的人四個勾選照舊。開機自動啟動預設勾：.exe 看 installer-choices.json，ZIP 看 Setup.bat 給的 SYNOX_SETUP_AUTOSTART。自己另外打開精靈時不勾，不會偷改你關掉的設定。

新的自訂勾了「全部官方工具」

按「完成並開始」時先裝完再開 SYNOX，畫面寫「正在裝全部官方工具…請不要關掉這個視窗」。只裝一次；有沒裝成的，之後到網頁「設定」的工具庫補。

已有AI 那一頁接得上

安裝時已經裝好 Claude Code 的話，這頁直接顯示「找到了」，只剩登入一次。沒裝成的話，「一鍵安裝（PowerShell）」按鈕還在。

⏳ 尚未完成改名成「設定精靈」

視窗標題還是「SYNOX 安裝精靈」。安裝程式和開始功能表已經叫它「設定精靈」，精靈自己的標題還沒跟著改。

  • Setup.bat：語言（Enter＝Windows 的顯示語言）→ 一題「建議／自訂」；-Custom、-UseSystemPython。
  • 設定精靈：從安裝程式來只剩「立刻開啟」；開機自動啟動預設開；「全部官方工具」（synox tools install --all）；教學那一行。
  • 新手教學的引擎：/tutorial、「開始教學」，內建一份基礎教學。
  • installer_ci.py check-iss：不用 Windows 也能檢查安裝腳本和 12 種語言的字。
  • 🧪＝寫了，但還沒在真的 Windows 上試過。

擁有者的決定・2026-11-13

九個問題都決定了，多一個新的

綠色＝已決定。Q1、Q2 沒有另外回覆，照建議做。Q6 的簽章留一半之後再決定。Q10 是實作時才冒出來的，還沒決定。

  1. 「建議」安裝要不要開機後自動啟動？（已決定）

    沒開的話，重開機之後手機上的助理就不回了、提醒也不響，不懂電腦的人會以為壞掉。沒有另外回覆，照建議做。

    決定要，預設勾。視窗看得到、隨時能關；在「自訂」可以取消。

  2. 「建議」安裝要不要順便裝 Claude Code？（已決定）

    好處是設定精靈預設的 AI 就是它，裝好只剩登入。代價是要上網、會執行官方網站的安裝指令、裝在 SYNOX 資料夾外面。沒有另外回覆，照建議做。

    決定要，當成可以不裝的最後一步：這台還沒有才裝，失敗不擋安裝，畫面上寫明「需要上網、裝在你的使用者資料夾」。ADR 0003 那一句已經改了。實測被防毒攔的話，退回成只在設定精靈裡按按鈕才裝。

  3. 「建議」要裝哪些工具？（已決定）

    擁有者決定：「建議」＝只有環境＋新手教學。SYNOX 一開始是空的；使用者跑教學（/tutorial、「開始教學」）、看懂這個程式，再自己挑工具。理由：希望大家先了解、再選擇，不要一裝好就一堆東西。

    決定不預先裝任何工具，也沒有「入門組合」。教學是 SYNOX 核心的一部分（同一個核心，能把畫面上的按鈕亮起來），隨時能重看。「自訂」裡有一項「全部官方工具都裝（不建議）」，預設不勾，小字寫「建議做完教學後再自己挑」。

  4. 要不要有「我同意授權條款」那一頁？（已決定）

    擁有者決定：不要。歡迎頁像 Apple 那樣越少越好：「歡迎使用 SYNOX，用得開心。」加 2 到 4 個短句，讓人不用多想。

    決定拿掉「我同意」那一頁。歡迎頁只放一行小字：個人使用免費；商業使用請看 AGPL-3.0 條款（連結）。繼續安裝就代表同意。授權檔照樣裝進資料夾。

  5. SYNOX 自帶的 Python 用哪一種？（已決定）

    擁有者決定：不用 uv。擁有者比較喜歡一般的 venv，也不想在電腦上多一個 uv。.exe 和 ZIP 用同一份固定版本的獨立版 CPython（python-build-standalone，本來就帶 tkinter）。

    決定照固定的網址＋SHA256 取得，放進 SYNOX 資料夾：ZIP 在安裝時下載；.exe 在打包時就放進去，使用者什麼都不用下載。接著是一般的 python -m venv .venv。SYNOX 資料夾以外什麼都不動：不碰 PATH、登錄檔，不用管理員。

  6. 安裝程式要不要簽章？（alpha 已決定）

    alpha 先不簽。下載頁放 SHA-256，加上過 SmartScreen 的兩步圖解（失敗畫面 3）。

    之後再決定公開宣傳之前，再看要不要用雲端簽章服務（例如 Microsoft 的 Trusted Signing，大約是每月付費）。

  7. 安裝程式的語言怎麼選？（已決定）

    擁有者決定：語言最先選。安裝程式一打開就是第 1 頁「選語言」（預選 Windows 的顯示語言，列 12 種，原文名＋英文名）；之後安裝程式的每一頁、設定精靈都用這個語言。ZIP 路徑也是先問語言。

    查過了Inno Setup 6.7.4 附官方語言檔的有 8 種：Español、Français、Deutsch、Português (Brasil)、Русский、العربية、日本語、한국어；English 是內建的。한국어 和 العربية 都有官方檔。只有繁體中文、简体中文、हिन्दी 沒有，見 Q10。我們自己的字 12 種都翻了，缺的句子退回 English。

  8. ZIP 路徑的「建議／自訂」要長什麼樣？（已決定）

    文字視窗留著。大多數人走 .exe；ZIP＋Setup.bat 是另一種方法，也給開不了 .exe 的人用。

    決定第一題問語言，按 Enter 的預設是 Windows 的顯示語言。接著問一題：按 Enter＝建議，輸入 C＝自訂。不另外做視窗。

  9. 解除安裝時要不要提供「連我的資料也一起刪除」？（已決定）

    今天安裝程式的解除安裝一律留下設定和資料；要刪資料得到 Uninstall.bat 選第 3 項並輸入 DELETE。

    決定要，給一個預設不勾的選項，勾了之後再確認一次。預設行為不變：資料留著。已經做好（解除安裝畫面）。

  10. 非官方的三個 Inno 語言檔要不要用？（還沒決定）

    繁體中文、简体中文、हिन्दी 的 Inno 語言檔是網友貢獻的，放在 Inno Setup 的 repo 和網站上，但檔頭沒有寫授權。不放的話，這三種語言的「下一步」「安裝」「取消」和安裝位置那一頁是英文；我們自己寫的字照樣是翻好的。

    建議確認授權沒問題就用：放進 setup/installer/lang/inno/，保留檔頭的譯者姓名，在第三方授權清單寫來源和 SHA256。確認不了就維持英文按鈕。細節在 docs/release-build.md。
