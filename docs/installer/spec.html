一句話目標

下載一個檔案，一路按「下一步」，SYNOX 就能用。

不懂電腦的人用建議值就全部裝好；懂的人可以自己調。這台電腦原本的 Python、Conda 和其他程式，一樣都不動。

5次點擊走完建議安裝：3 次「下一步」、1 次「安裝」、1 次「完成」
0個指令。全程沒有黑色視窗，不用打字
0次系統管理員密碼。裝在你自己的使用者資料夾
1個資料夾。程式、SYNOX 自己的 Python、你的資料都在裡面

五條原則

每一頁畫面、每一句話都拿這五條檢查。有一條不過，就還不能出貨。

  • 不用開終端機

    從下載到手機收到「我在了」，使用者只按按鈕、貼一次 token。看不到黑色視窗，也不用知道 Python 是什麼。

    檢查方法：找一位不寫程式的人，不給任何提示，看他能不能自己裝完。

  • 講白話

    畫面上不出現 venv、pip、PATH、HKCU 這些字。要講就講它做什麼：「SYNOX 自己的 Python」「點兩下就能安裝」。

    工程用語只放在「顯示詳細過程」和紀錄檔裡。

  • 失敗時說下一步

    每個錯誤畫面都回答三件事：發生什麼事、你的東西有沒有受影響、現在該按哪一顆。不丟錯誤代碼給使用者。

    見第 6 節的五個失敗畫面。

  • 建議值先選好

    每個問題都有一個已經選好的答案，直接按「下一步」就是完整可用的 SYNOX。想改的人選「自訂」，像 Git for Windows 那樣一項一項調。

  • SYNOX 資料夾以外的東西，你選了才動

    程式、SYNOX 自己的 Python、資料都放在同一個資料夾。資料夾外面只會做你在畫面上看得到、而且勾了的事（捷徑、開機啟動、檔案類型、Claude Code），每一項都能取消，解除安裝時會收乾淨。

先說清楚

新的⏳ 自帶 Python 正在做

這頁要做到

  • 在使用者做任何選擇之前就講明白：這台電腦的 Python／Conda 可能會干擾，所以 SYNOX 不碰它們。
  • 黃色那一格是偵測到才出現的：找到 Conda、Microsoft Store 的 python 捷徑、或 PATH 上別的 Python 時，把找到的東西列出來，再說一次「不會用到」。什麼都沒找到就不顯示。
  • 只有說明，沒有要選的東西。直接按「下一步」。
  • 不寫「虛擬環境」「PATH」。SYNOX 的 Python 不加進 PATH，別的程式看不到它。

怎麼做

Inno Setup
自訂頁 CreateCustomPage(wpWelcome, …)。偵測寫在 [Code]：CONDA_PREFIX、%USERPROFILE%\anaconda3／miniconda3、%LOCALAPPDATA%\Microsoft\WindowsApps\python.exe（Store 的捷徑）。只讀，不改。
bootstrap
預設只用 SYNOX 資料夾裡的 Python；不再找 py、PATH、winget。另一個工作正在改（用 uv 把 Python 裝在 SYNOX 資料夾內）。
今天
bootstrap.ps1 會先找系統的 py／python，找不到才用 winget 或可攜版。這正是要拿掉的行為。

已有文字要改

安裝之後

接著的設定精靈

安裝程式負責「把程式裝好」，設定精靈負責「接上你的帳號」。精靈今天就有，支援 12 種語言；下面是它現有的五頁，字是現在程式裡的字。

已有語言那一頁會自動跳過

安裝程式已經知道語言，用 --lang 交給精靈。只有直接打開精靈、又沒選過語言的人才會看到「Language / 語言」。

要改最後一頁不再重問一次

今天「差不多了」有四個勾選：桌面捷徑、開機啟動、.synoxpack、立刻開啟。從安裝程式來的人前三項已經決定了，這頁只留「完成後立刻開啟 SYNOX」。從 ZIP 來的人四項照舊，預設值跟安裝程式一樣。

要改AI 那一頁接得上

安裝時已經裝好 Claude Code 的話，這頁直接顯示「✅ 找到了」，只剩登入一次。沒裝成的話，現有的「一鍵安裝（PowerShell）」按鈕還在。視窗標題建議從「安裝精靈」改成「設定精靈」，免得跟安裝程式搞混。

照實說

現在做到哪裡

這一頁是設計稿。上面的視窗都是畫的，還沒有任何一頁在 Windows 上跑過。

⏳ 尚未完成：SYNOX-Setup-<版本>.exe 從來沒有打包過。Inno Setup 的腳本和備料腳本寫好了，但沒有實際執行過，也沒有在空白的 Windows 上裝過。這份規格裡所有關於 Windows 行為的描述都是待實測。

已經有的

  • Setup.bat＋bootstrap.ps1：找或裝 Python、建立環境、裝套件、登記 .synoxpack、打開精靈。
  • 設定精靈（Tk 視窗）：語言、給誰用、Telegram token 與配對、AI 來源、完成頁四個勾選；12 種語言。
  • 精靈裡的 Claude Code 一鍵安裝（官方 PowerShell 指令）。
  • setup\installer\synox.iss：每個使用者自己裝、不用管理員、裝到 %LOCALAPPDATA%\Programs\SYNOX；只有英文；最後開 Setup.bat。
  • scripts\stage_installer.py：把 Python、離線套件、工具庫排好給 Inno Setup 用。
  • Uninstall.bat＋uninstall.ps1：四種程度的移除。
  • 工具庫的 tools-0.2.0.zip（SYNOX_Libs v0.2.0）。

正在做

  • SYNOX 自帶的 Python：bootstrap 改成用 uv 把 Python 裝在 SYNOX 資料夾裡，預設不碰 Conda、Microsoft Store、系統的 Python。

一定要在真的 Windows 上試的事

畫面與時間附的 Python 能不能開出設定精靈的視窗；整個安裝實際要幾分鐘、佔多少空間；安裝中會不會閃出黑色視窗。
保護機制沒簽章時 SmartScreen 的實際畫面；Microsoft Defender 會不會攔安裝程式裡的 PowerShell 步驟，特別是安裝 Claude Code 那一行。
各種電腦使用者名稱或路徑有中文、空白；桌面被 OneDrive 接管；已經裝了 Anaconda；公司電腦限制 PowerShell；沒有網路。

請擁有者決定

九個要你點頭的問題

每一題都附上建議。沒有回覆的話，就照建議做。

  1. 「建議」安裝要不要開機後自動啟動？

    今天設定精靈這一項預設是不勾。但沒開的話，重開機之後手機上的助理就不回了、提醒也不響，不懂電腦的人會以為壞掉。

    建議要，預設勾。視窗看得到、隨時能關，自訂可以取消。

  2. 「建議」安裝要不要順便裝 Claude Code？

    好處是設定精靈預設的 AI 就是它，裝好只剩登入。代價是這一步要上網、會執行官方網站的安裝指令、裝在 SYNOX 資料夾外面，跟 ADR 0003「安裝程式不跑任何從網路下載的東西」不一致，防毒軟體也可能攔。

    建議要，但只在這台還沒有時才裝、放在最後一步、失敗不擋安裝，並且在畫面上寫明「需要上網、裝在使用者資料夾」。同時修改 ADR 0003 那一句。實測被防毒攔的話，退回成只在設定精靈裡按按鈕才裝。

  3. 「全部幫我裝好」的工具要裝到什麼程度？

    ADR 0003 現在寫的是「不自動全裝，要什麼自己挑」。但空的 SYNOX 對新手來說等於什麼都不會。

    建議9 個工具的檔案都放好，只自動裝「入門組合」（工具庫目錄裡的 starter，例如隨手記、記帳），照原本的安全檢查走，不裝需要輸入發行者名字的那一類。入門組合放哪幾個由你定。

  4. 要不要有「我同意授權條款」那一頁？

    今天的 synox.iss 會顯示整份 LICENSE 並要求勾「我同意」。多一頁、全是英文法律文字，而 AGPL 並不要求使用者點同意才能使用。

    建議拿掉那一頁，在歡迎頁放一行「繼續安裝代表你同意授權條款」加連結，授權檔照樣裝進資料夾。

  5. .exe 附的 Python 用哪一種？

    現在的設計是官方的「可攜版」Python，它沒有視窗元件，要另外複製 tkinter 進去，能不能成功還沒驗證（原本的 QD3）。ZIP 路徑正在改用 uv 下載的獨立版 Python，那種通常本來就帶 tkinter。

    建議兩條路用同一種：發佈時先用 uv 把同一版獨立 Python 抓好、放進安裝程式。少維護一套，也可能順便解決開不出視窗的問題。等另一個工作做完再確認。

  6. 安裝程式要不要簽章？（原本的 QD1）

    沒簽章時每個人第一次執行都會看到 SmartScreen 的藍色警告，這是「一路按下一步」最大的破口。

    建議alpha 先不簽：下載頁放 SHA-256 和兩步圖解。公開宣傳之前改用雲端簽章服務。

  7. 安裝程式自己的畫面要做幾種語言？

    設定精靈有 12 種語言，但安裝程式的每一頁都要另外翻一次。

    建議先做繁體中文和 English，其他語言的 Windows 顯示 English。SYNOX 本身的語言仍然可以選 12 種。

  8. ZIP 路徑的「建議／自訂」要長什麼樣？

    ZIP 這條路在 Python 裝好之前開不出精靈的視窗，只有 Setup.bat 的文字視窗。今天它第一題是問語言。

    建議文字視窗開頭先印「先說清楚」那三行，再問一題：按 Enter 照建議全部裝好，輸入 C 自訂。語言自動跟 Windows 一樣。不另外做視窗；想要完整畫面的人用 .exe。

  9. 解除安裝時要不要提供「連我的資料也一起刪除」？

    今天安裝程式的解除安裝一律留下設定和資料；要刪資料得到 Uninstall.bat 選第 3 項並輸入 DELETE。

    建議要，給一個預設不勾的選項，勾了之後再確認一次。預設行為不變：資料留著。
