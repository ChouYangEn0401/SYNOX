# 手機入口的打開流程這樣可以嗎？

- **狀態**：待處理（照建議先做了，等擁有者確認）
- **擁有者原話**：「我希望整個流程是更簡單的，可以被 Synox 去做出來。但是安全性就會變得很重要。」

## 問題一句話
要用手機入口，事前要做兩步：①設定手機驗證器、核准你自己裝的 cloudflared（對雜湊）；②在主機台打開總開關。之後每次用：Telegram 打 `/app_remote money` → 輸驗證碼 → 收到一次性連結 → 手機打開再輸一次碼 → 30 分鐘一定關（10 分鐘沒動也關）。

## 脈絡
- 已定的：用 cloudflared 臨時網址、手機進門要第二組碼、手機上不能匯出也不能做危險動作、AI 和排程開不了。
- 臨時網址開著時，網路上任何人都敲得到門（但只通到那一個工具、要一次性連結＋驗證碼）；Cloudflare 看得到經過的內容。

## 選項
| 選項 | 一句話 | |
|---|---|---|
| A | 維持現在的流程 | **建議（已做）** |
| B | 改成私人網路（例如 Tailscale）：更安全，但手機和電腦都要裝、會動到網路設定 | |
| C | 縮短時限（例如 15 分鐘） | |

## 驗收
- 跟「在別台電腦實測」那張一起驗：從頭到尾走一次，計時、截圖。

## 不要做的事
- SYNOX 不自己下載 cloudflared；不要把主機台接到通道上。
