# 網頁介面重新設計（2026-11-12，分支 `feat/ui-redesign`）

**結論**：網頁版整個重畫了，功能和安全都沒動。改的是：左側欄的版面（參考 OpenClaw／Hermes）、深色的層次與質感（參考 ISDPCS）、
淺色與手機的簡約規則（參考記帳專案）。
**怎麼看**：雙擊 [preview.html](preview.html) 看電腦版，雙擊 [preview-phone.html](preview-phone.html) 看手機寬度。用的是假資料，
不用開 SYNOX、不連網。截圖在 [screenshots/](screenshots/)。

## 之前哪裡醜、哪裡難用 → 怎麼改

| # | 之前 | 現在 |

| 2 | 每張卡都是同樣的白底細框，按鈕也全長一樣，看不出哪個是主要動作 | 背景、卡片、凹槽分成三層（深色另外加內側高光和陰影）；一張卡只有一個實心主要按鈕，其他用外框或透明按鈕 |
| 3 | 深色只是把顏色反過來，平平的；主色是普通的藍 | 深色照 ISDPCS 的分層配色，主色換成青綠（淺色用深一點的青綠，對比 ≥ 4.5:1），背景有一圈很淡的光 |

| 5 | 設定頁的 pack 表格只有文字，「掃描沒過」和「可以用」看起來一樣 | 狀態改成徽章：綠＝可以用、黃＝還沒接上、紅（方點）＝壞了或拒絕；顏色一定配文字，原因放在下一行小字 |

## 三個參考對象各取什麼

| 參考 | 取了什麼 | 沒取什麼（為什麼） |
|---|---|---|
| **OpenClaw**（Control UI） | 資訊架構：左側欄＝主導覽＋對話紀錄（它的 Sessions），左下角是身分，對話上方有標題列 | 浮動面板、多人在線、模型選擇器等（SYNOX 沒有這些功能，硬做會變複雜） |
| **Hermes Agent**（web dashboard） | 側欄分頁、設定拆成一張張卡（AI、通道、功能、帳號、備份）、金鑰只顯示「有填／最後 4 碼」（SYNOX 原本就是這樣）、狀態用顏色區分 | 8 套主題和字型選擇器（先跟隨系統就好，選項越多越難用）、網頁終端機 |
| **ISDPCS** | 深色配色的分層（底／面板／凹槽）、卡片的內側高光加負擴散陰影、所有淡色都從主色調出來、`cubic-bezier(.2,.9,.3,1)` 的動態曲線、3px 聚焦光圈、背景右上角的淡光 | 霓虹發光和大量動畫（SYNOX 是給一般人用的工具，要穩重一點）、14px 的高密度排版 |
| **記帳專案**（金流簿） | 淺色配色、`X`／`X-soft` 成對的狀態色、內容單欄置中（設定頁最寬 820px）、平的圓角卡片（14px）、一頁一個主要動作、狀態用顏色＋文字＋形狀、手機規則（14／16／44px）、底部分頁、反色的提示條 | Google Fonts（SYNOX 的網頁不准載外部資源，要能離線用），改用系統字型 |

## 版面與頁面

- **外框**：電腦版是左側欄（252px）加內容；手機（≤ 760px）是上方列（品牌、對話紀錄橫向捲動、登出）加底部三個分頁。
- **登入**：沒有側欄，只有一張置中卡片，兩個步驟加編號。
- **對話**：對話紀錄在左側欄，主區是一張大卡（標題列、訊息、輸入區）。訊息泡泡：自己的靠右、淡青綠；SYNOX 的靠左、有框；系統說明置中、膠囊狀。按鈕卡（核准卡）兩欄並排。
- **工具**（2026-11-12 分支 `feat/tools-page-groups` 重做）：頁內左邊是「群組」，群組裡的工具用分頁隔開；每個工具分頁有說明、
  指令卡（可以收合；effect 徽章；參數照 pack.json 的 `fields` 產生表單：必填標籤、下拉、預設值、說明）、「會送出：…」的指令預覽、
  「執行」（危險的先在畫面上問一次）。按「編輯」可以新增／改名／刪除群組、排序、把工具移到別的群組，存在每個人自己的偏好。
  手機寬度：群組變成上面一排可以橫捲的膠囊，分頁也橫捲。程式在 `static/tools.js`、`static/tools.css`（伺服器送出頁面時
  放進 app.html 的 include 標記，同一個 nonce）；規則見 [../tools.md](../tools.md)「網頁工具頁」。
  預覽：`preview.html#tools`、`preview.html?tooledit=1#tools`（群組編輯可以真的按，存在那一頁的記憶體裡）。
- **設定**：單欄卡片（AI、聊天通道、功能、帳號、備份），每張卡的開頭是圖示方塊、標題和一句說明。
- **伺服器產生的小頁**（登入確認、登入連結不能用）：同一套顏色的置中卡片。

## 沒做的與限制

- **安裝精靈（tkinter）沒改**：它不是網頁，CSS 套不上去；要一致得另外寫 ttk 主題或改成網頁精靈（QuestionToUser Q5）。
- 網頁的功能、API、CSRF、一次性登入、本機擁有者登入、CSP（nonce、沒有外部資源、沒有 inline 事件）都沒動；只改了 HTML 結構、CSS 和少量畫面用的 JS
  （目前分頁的標示、對話標題、狀態徽章、左下角身分、輸入框自動長高）。
- 預覽是真的 `app.html` 加上假資料，由 `scripts/make_ui_preview.py` 產生；改了樣式要重跑，`tests/test_ui_preview.py` 會檢查有沒有同步。
- 手機畫面只用 Chrome 的 390px 框看過，沒在真的手機上看過。
