    請先登入

    沒有密碼：一次性的登入連結就是鑰匙，不要轉給別人。

    1. 在跑 SYNOX 的這台電腦上：雙擊桌面的「SYNOX」捷徑（或 SYNOX 資料夾裡的 Open-SYNOX.bat），它會打開一個新的一次性登入連結，按頁面上的「登入」就好。
    2. 有接 Telegram／Discord 的話，也可以跟你的 SYNOX bot 打 /web 拿連結（7 天內有效、只能用一次）。

    這個網頁只在跑 SYNOX 的那台電腦上打得開（127.0.0.1）。

    AI 從哪裡來

    不確定電腦撐不撐得住？按「看建議」：只讀取模型資料與這台電腦的記憶體，不會載入模型。建議值都是估算。

      逾時：模型只要還在回應就不會被中止；完全沒有進展超過 450 秒才中止， 總上限 1800 秒（config.json 的 llm.timeout／llm.max_total_timeout）。

      要先裝 Claude Code 命令列版（不是 Claude Desktop）。複製下面一行，貼到終端機執行； 裝完在終端機輸入 claude 登入一次，再回來按「測一下」。

      Windows（PowerShell）
      irm https://claude.ai/install.ps1 | iex
      Linux／macOS
      curl -fsSL https://claude.ai/install.sh | bash

      官方安裝說明 ．裝好後如果還是找不到，重開 SYNOX（它啟動時看到的 PATH 才是新的）。

      ☕

      保持清醒

      像一個穩定的 heartbeat：維持系統運轉，但螢幕可以暗（保護螢幕或省電）。

      ⚠️ 開啟後會覆蓋 Windows 電源選項裡的「睡眠」設定：電腦不再自動睡眠。螢幕仍可照電源計畫，或設定「閒置 N 分鐘後主動關螢幕」變暗／關閉，以保護螢幕、省電。闔上筆電蓋、手動睡眠、低電量、Windows Update 重開機擋不住。

      💾

      備份

      下載整個 data 資料夾（筆記、記帳、提醒、使用者…），用這台電腦的保管箱金鑰加密。只有同一台電腦、同一個 Windows 帳號解得開。

      💬

      聊天通道

      貼上 bot 的 token，先檢查再存（token 存好之後不會再顯示）。改了要重新啟動 SYNOX 才生效。

      💬 目前只能一對一私訊：要在 Telegram 或 Discord 裡私訊 bot 才會回你。 把 bot 加進 Telegram 群組、Discord 伺服器的頻道或「社群」裡 @ 它，不會有用（指令與 AI 在群組、頻道裡都被擋掉，這是為了不讓別人碰到你的資料）。

      ⚠ 聊天通道的設定改了，要重新啟動 SYNOX 才會生效： 先雙擊 Stop.bat，再雙擊桌面的 SYNOX 捷徑。在那之前 bot 不會上線、也不會回你。

      Telegram

      第一次用？看圖文教學：怎麼跟 @BotFather 拿 token、配對、常見問題。

      Discord

      邀請連結：把 bot 加進任何一個你也在的伺服器，之後從成員清單點它就能私訊（bot 不會在伺服器的頻道裡講話）。

      📦

      安裝新功能

      選一個 .synoxpack（pack 資料夾壓成的 zip），先看安全檢查報告，按「確認安裝」才會裝。 雙擊 .synoxpack、Install-Pack.bat 或 synox install <檔> 開的報告也會直接出現在這裡。
