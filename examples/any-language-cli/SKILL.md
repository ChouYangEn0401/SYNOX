# 📋 備忘清單

## 什麼時候用
- 「記一下：買牛奶」→ `anylang__add`：text＝買牛奶（必填，一行）
- 「我的清單有什麼」→ `anylang__list`
- 「清單全部清掉」→ `anylang__clear`：工具會先送確認卡給使用者，使用者按 ✅ 才刪

## 注意
- 參數名就是欄位名；值一律是字串。text 不能換行、不能以 `-` 開頭。
- `clear` 送出確認卡之後就停下來等使用者，不要再叫一次。
